## Overview

This research presents the development and deployment of an intelligent campus assistive chatbot using natural language processing and deep learning techniques. Published in IEEE CSITSS (Conference on Signal and Information Processing, Networking and Computers) in 2021, this work demonstrates practical NLP applications in educational environments.

**Publication:** IEEE CSITSS, December 2021
**[Read the full paper](https://ieeexplore.ieee.org/document/9683551)**

## Project Context

This project was developed during my internship with Cisco at R.V. College of Engineering, Bangalore. The chatbot was designed to assist students, faculty, and visitors with common queries about the campus, courses, events, and facilities.

## Key Features

### NLP Pipeline Architecture

The chatbot employs a sophisticated NLP pipeline consisting of:

1. **Text Preprocessing:** Tokenization, lowercasing, and stemming using NLTK
2. **Feature Extraction:** Bag of Words (BoW) representation
3. **Intent Classification:** Sequential Neural Network
4. **Response Generation:** Template-based and dynamic responses

### Neural Network Architecture

- **Input Layer:** Bag of Words feature vectors
- **Hidden Layers:** Dense layers with ReLU activation
- **Output Layer:** Softmax activation for multi-class intent classification
- **Accuracy:** 89% on 100 test interactions
